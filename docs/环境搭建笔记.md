# 环境搭建笔记

> 记录 Docker / Hive / MySQL 环境搭建过程中遇到的问题与解决方案（子任务 2 交付物）。

## 一、环境信息

| 组件 | 版本 | 说明 |
|---|---|---|
| 操作系统 | Windows | 需 WSL2 后端 |
| Docker Desktop | 待安装 | 官网下载，勾选 WSL 2 backend |
| Hive | 4.0.0（apache/hive 镜像） | 含 Metastore 与 HiveServer2 |
| MySQL | 8.0 | 作 Metastore 元数据库 |

## 二、搭建步骤（对应操作手册）

1. 安装 Docker Desktop（勾选 WSL 2 backend），安装后重启电脑
2. 验证：`docker --version`、`docker compose version`
3. 项目根目录执行 `docker compose up -d` 拉起 mysql / hive-metastore / hive-server
4. `docker ps` 确认三个容器 Up
5. 连接验证：`docker exec -it hive-server beeline -u jdbc:hive2://localhost:10000`
6. 执行 `show databases;`、`create database if not exists ydsh_ods;`

## 三、遇到的问题与解决方案

### 问题 1：Edge 下载 Docker Desktop 安装包失败（ERR_CONNECTION_RESET）
- 现象：浏览器访问 `desktop.docker.com` 下载页显示"无法访问此页面"，右上角防火墙显示"公用网络（使用中）"
- 排查：命令行 `curl -I` 访问同一 URL 返回 `HTTP/1.1 200 OK`，`Content-Length: 641758128`
- 原因：浏览器层面的网络/代理问题，非目标站点不可达
- 解决：改用命令行下载（支持断点续传，不受浏览器代理设置影响）

```bash
curl -L --retry 3 -C - -o "$HOME/Downloads/DockerDesktopInstaller.exe" \
  "https://desktop.docker.com/win/main/amd64/Docker%20Desktop%20Installer.exe"
```

### 问题 2：静默安装 Docker Desktop
- 命令：`DockerDesktopInstaller.exe install --quiet --accept-license --backend=wsl-2`
- 要点：需管理员权限（会弹 UAC），安装耗时约 2 分钟，返回码 0 表示成功
- 安装后版本：Docker 29.9.2 / Docker Compose v5.6.1

### 问题 3：引擎起不来，日志报 `Access is denied`（写 ~/.docker/config.json 失败、调 wsl.exe 失败）
- 现象：`docker ps` 报 `open //./pipe/docker_engine: The system cannot find the file specified`
- 日志：`C:\Users\<用户>\AppData\Local\Docker\log\host\com.docker.backend.exe.log` 中
  - `rename <HOME>\.docker\daemon.json: Access is denied`
  - `c:\windows\system32\wsl.exe --version failed: fork/exec ...: Access is denied`
- 原因：Docker Desktop 由受限制的进程启动，继承了进程策略限制，导致无法写用户目录、无法调用 wsl.exe
- 解决：**从开始菜单（或桌面快捷方式）手动启动 Docker Desktop**，让它作为独立进程运行；确认系统托盘鲸鱼图标变为绿色

### 问题 4：WSL2 未安装导致引擎无法启动
- 前置检查：`VirtualizationFirmwareEnabled: True`（BIOS 已开启虚拟化），但 `HypervisorPresent: False`、无已安装发行版
- 处理：Docker Desktop 首次启动会提示安装/enable WSL2（需管理员 + 重启一次）

### 问题 5：HiveServer2 起不来（Metastore 未就绪）
- 原因：Hive 依赖 HDFS + Metastore（MySQL），启动有顺序依赖
- 解决：compose 中已配置 `depends_on: condition: service_healthy`，mysql 健康检查通过后再启 metastore

### 问题 6：10000 端口被占用
- 排查：`netstat -ano | findstr 10000`
- 解决：结束占用进程，或修改 compose 端口映射

### 问题 7：CSV 导入行数与预期不符
- 原因：表头被当成数据 / 分隔符不匹配
- 解决：建表加 `tblproperties('skip.header.line.count'='1')`，确认 `FIELDS TERMINATED BY ','`


## 四、常用命令备忘

```bash
docker compose up -d                       # 启动全部服务
docker compose down                        # 停止并移除容器
docker ps                                  # 查看运行容器
docker logs -f hive-server                 # 追踪 Hive 日志
docker exec -it hive-server bash           # 进入 Hive 容器
beeline -u jdbc:hive2://localhost:10000    # 连接 Hive
```
