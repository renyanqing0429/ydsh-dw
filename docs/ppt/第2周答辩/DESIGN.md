# DESIGN.md — 第 2 周阶段答辩 PPT

## 一、需求对齐

| 维度 | 结论 |
|---|---|
| 主题 | 云购生活新零售企业数仓 · 第 2 周阶段答辩 |
| 目标 | 按任务书第六部分「6~8 分钟汇报 + 教师提问」要求，讲清修复率、清洗策略、四层架构、DWD 建模规范、分析发现 |

## 二、全局视觉约定

### ① 画布与安全区
- 画布 1280×720
- 左右安全区 60px；顶部标题条高 64px 满幅；内容区宽 1160、高 580（含 24px 上留白）
- 页脚固定：距底 30px，高 20px，左右 60px

### ② 配色（学术宝蓝 + 白底）

| 槽位 | Hex | 用途 |
|---|---|---|
| 主色 | `#1E4FA8` | 顶条、章节序号、强调 |
| 辅色 | `#3D7BD9` | 图表第二色、次级标识 |
| 浅底 | `#E8EFF8` | 结论条、表头底 |
| 强调红 | `#D9534F` | 关键异常数据，全篇 ≤3% |
| 正文 | `#1A2230` | 主张 |
| 次级文字 | `#4A5568` | 说明 |
| 弱化文字 | `#8B97A8` | 页脚、注释 |
| 分隔线 | `#D6DCE5` | 1px 贯穿细线 |
| 底色 | `#FFFFFF` | 页面主背景 |

纪律：白底 ≥60%，蓝族 20~40%，红 ≤3%，无金色、无渐变、无紫色。

### ③ 字体
- 全篇单一字体家族：`Microsoft YaHei`（思源黑体在 Windows 答辩机缺失，回退雅黑，字重承担层级）
- 字号阶梯：封面主标 64 / 章节大字 120 / 巨型数字 76 / 页主标 32 / 卡内小标 24 / 正文 19 / 表格 17 / 页脚 14

### ④ 视觉母题
- 顶部 64px 深蓝标题条：左标题、右「01 · Data Cleaning」章节标识
- 内容区首行统一为「关键判断」细线 + 一句话论断，再进主体
