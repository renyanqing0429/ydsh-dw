## 三、环境搭建

**技术栈**：Docker Compose + Apache Hive 3.1.3 + Hive Metastore（MySQL 8 后端）+ HDFS + Beeline

三容器一键编排：`hive-server`（HiveServer2 / 10000）、`hive-metastore`（9083）、`metastore-mysql`（3306）。

**关键决策——模拟数据先行**：官方数据未到位时，先用 Python 生成**等量**模拟数据（115,809 行）把整条流水线跑通。官方数据下发后只需替换 CSV 文件，SQL 脚本零改动即可复用。

**14 个环境问题全部解决并记录**，按类型分布：

| 类型 | 数量 | 代表问题 |
|---|---|---|
| 安装与引擎 | 4 | Edge 下载中断、静默安装、WSL2 未装、`~/.docker/config.json` 权限拒绝 |
| 容器与服务 | 6 | Metastore 未就绪导致 HS2 起不来、端口占用、MySQL 驱动类找不到、容器 Exited(255) |
| 数据导入 | 1 | CSV 导入行数与预期不符 |
| 工具链 | 2 | Git Bash 路径改写、管道执行 SQL 中文注释变问号 |
| 网络 | 1 | `registry-1.docker.io` 拉取超时 |

每个问题均按「现象 → 原因 → 解决方案 → 验证方式」四段式记录，可直接复用。

## 五、数据质量评估（五维度）

扫描发现 **7,900 处**脏数据，完整结果见 `docs/数据质量预评估表.xlsx`（8 个工作表）：

| 维度 | 主要发现 | 数量 |
|---|---|---:|
| **完整性** | email 缺失、商品上架日期缺失 | 204 |
| **唯一性** | 订单整行重复 + 内容冲突 | 600 |
| **有效性** | 枚举脏值（支付/状态/渠道/性别/行为类型） | 6,506 |

- 日期格式：`2024/01/15` 与 `2024-01-15` 并存（1,902 行）
- 逻辑矛盾：优惠券金额 > 支付金额（324 行）、订单金额为负（310 行）、年龄 150 岁（27 行）

## 六、数据清洗成果

| 清洗项 | 处理前 | 处理后 | 方法 |
|---|---:|---:|---|
| 用户年龄异常 | 78 | **0** | 均值 41 填充 |
| 商品上架日期缺失 | 11 | **0** | 填充处理 |
| 订单重复行 | 15,600 | **15,000** | `ROW_NUMBER()` 按 `order_time` 保留最新 |
| 去重后残留复检 | — | **0** | 二次校验确认 |

**清洗原则（可追溯）**：

- 邮箱缺失**打标保留**（`is_email_missing` 字段）而非直接删除，避免误删有效用户
- 订单去重保留**时间最新**的一条，符合业务语义
- 所有清洗动作均可通过 SQL 脚本重放，不依赖手工操作

一键复现：`bash tools/run_pipeline.sh all`

## 七、AI 协同情况

本周全程使用 AI 辅助开发，形成 **9 条协同记录**，覆盖：环境方案设计、Docker 排错、SQL 编写、质量扫描脚本、Excel 生成、文档撰写等。

**协同带来的实际收益**：

1. 环境问题平均定位时间从"反复试错"缩短到"一次定位"（14 个坑全部一次解决）
2. 质量扫描 SQL 从零编写到跑通仅 1 轮
3. 数值全部来自 beeline 实测，AI 负责格式化与交叉校验，避免估算偏差

**一次纠错教训**：初版报告把枚举脏值估算为「约 2,500 行」，后续实测发现漏算行为类型 3,672 行，修正为 **6,506 行**。说明 AI 输出的估算值必须回到数据库实测校验，不能直接采信。

## 附录：复现步骤

```bash
# 1. 启动环境（需先启动 Docker Desktop）
cd ydsh-dw && docker-compose up -d

# 2. 等待 HiveServer2 就绪（约 20-60 秒）
#    端口探测：localhost:10000

# 3. 一键跑完整流水线（建库 → 建表 → 导入 → 质量扫描 → 清洗）
bash tools/run_pipeline.sh all

# 4. 单独补跑某一步（脚本会自动 DROP 重建，不会数据翻倍）
bash tools/run_pipeline.sh clean
```

**注意**：Windows Git Bash 下执行 docker 命令需设置 `MSYS_NO_PATHCONV=1`，否则路径会被改写（详见《环境搭建笔记》问题 11）。
